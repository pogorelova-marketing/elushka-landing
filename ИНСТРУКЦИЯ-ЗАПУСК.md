# Как запустить лендинг Ёлушка на elushka.ru

Сайт готов. Счётчик Метрики и цели уже вшиты в код — настраивать ничего не нужно,
только завести цели в интерфейсе Метрики (шаг 5).

Всего 5 шагов, примерно час работы.

---

## Шаг 1. Скачать файлы

1. Открыть https://github.com/pogorelova-marketing/elushka-landing
2. Зелёная кнопка **Code** → **Download ZIP**
3. Распаковать

---

## Шаг 2. Залить на хостинг

Скопировать файлы в корень сайта — папка `public_html` или `www`
(через файловый менеджер хостинга или FileZilla).

**Что заливать:**

```
index.html
privacy.html
sitemap.xml
assets/          ← вся папка целиком
```

**Что не заливать:** `data`, `tools`, `overview.md`, `README.md`,
`ИНСТРУКЦИЯ-ЗАПУСК.md` — это рабочие файлы, на сайте они не нужны.

`robots.txt` — отдельная история, о нём шаг 4.

⚠️ `index.html` должен лежать **в корне**: адрес `elushka.ru/index.html`,
а не `elushka.ru/какая-то-папка/index.html`. Иначе не будет картинок.

---

## Шаг 3. Домен и HTTPS

1. Направить домен **elushka.ru** на хостинг (A-запись, делается у регистратора)
2. Включить бесплатный SSL-сертификат — в панели хостинга, раздел «SSL»
3. Настроить переадресацию на `https://elushka.ru` с адресов
   `http://elushka.ru` и `www.elushka.ru`

Готово, когда в адресной строке появился замок.

---

## Шаг 4. Открыть сайт для поиска

Сейчас сайт спрятан от Яндекса и Google — так было нужно, пока шли согласования.
Запрет стоит **в двух местах**, снять надо оба.

### 4.1. robots.txt

В скачанной папке есть файл **`robots-production.txt`**.
Переименовать его в **`robots.txt`** и залить на хостинг.

Старый `robots.txt` (в котором написано `Disallow: /`) — не заливать вообще.

### 4.2. Строчка в двух файлах

Открыть `index.html` в Блокноте (не в Word!), найти вверху строку:

```html
<meta name="robots" content="noindex, nofollow">
```

Удалить её. **То же самое сделать в `privacy.html`.**

Перезалить оба файла на хостинг.

### 4.3. Проверить

- Открыть `elushka.ru/robots.txt` — должно быть написано `Allow: /`
- На главной нажать Ctrl+U (Cmd+Option+U на Mac), поискать слово `noindex` —
  найтись ничего не должно

Если пропустить этот шаг — сайт **никогда не появится в поиске**.

## Шаг 5. Цели в Метрике

Счётчик **100250379** (тот же, что на старом сайте) уже стоит на обеих страницах.
На превью-адресе он не работает специально, чтобы не мешать статистике —
заработает сам, как только сайт откроется на elushka.ru.

Код целей тоже вшит. Осталось создать сами цели в интерфейсе:

**Метрика → Настройка → Цели → Добавить цель → тип «JavaScript-событие»**

Создать шесть штук, идентификаторы вписать точно как в таблице:

| Название цели (любое) | Идентификатор | Когда срабатывает |
|---|---|---|
| Переход в магазин Max Christmas | `mc_shop` | кнопка «Перейти в каталог» |
| Переход на Wildberries | `wildberries` | кнопка Wildberries |
| Переход на Ozon | `ozon` | кнопка Ozon |
| Запрос оптового прайса | `opt_price` | «Получить оптовый прайс» |
| Клик по модели ёлки | `model_click` | карточка в каталоге |
| Клик по телефону | `phone_click` | номер в подвале |

Главные для отчётов — первые четыре: это и есть маршруты покупки из ТЗ.

**Ещё включите в настройках счётчика:** Вебвизор и карту скроллинга.
Для одностраничника это важнее обычных визитов — видно, до какого блока долистывают.

**Проверить, что работает:** откройте сайт, нажмите кнопку Wildberries,
затем в Метрике посмотрите отчёт «Конверсии» или Вебвизор — событие появится
в течение нескольких минут.

---

## Готово. Проверьте напоследок

- [ ] Сайт открывается на телефоне, ничего не съезжает вбок
- [ ] В блоке «Модели» работает шкала высот: меняешь высоту — меняются цены
- [ ] Фото отзывов открываются на весь экран по клику
- [ ] Кнопки ведут куда надо: каталог, WB, Ozon, оптовый прайс
- [ ] Внизу открывается политика конфиденциальности
- [ ] В адресной строке замок HTTPS
- [ ] В Метрике за сегодня появились визиты

Добавьте сайт в **Яндекс Вебмастер** и **Google Search Console**,
загрузите там `sitemap.xml` — так поисковики найдут сайт за дни, а не за недели.

## Цены обновляются сами

**Каждое 1-е число в 06:00 по Москве** GitHub сам скачивает свежий фид
Max Christmas, пересобирает каталог, скачивает новые фото товаров и сжимает их.
Ваш компьютер при этом может быть выключен.

Дата последнего обновления видна прямо на странице под каталогом — по ней
всегда понятно, свежие ли цены.

**Если цены поменялись срочно, между 1-ми числами:**

1. Открыть https://github.com/pogorelova-marketing/elushka-landing/actions
2. Слева выбрать «Обновление каталога из фида»
3. Справа кнопка **Run workflow** → зелёная кнопка **Run workflow**
4. Через минуту цены обновятся

⚠️ Автообновление работает, **только пока сайт живёт на GitHub Pages**.
Если перенесёте на обычный хостинг — после каждого обновления нужно будет
перезаливать файлы вручную (или настроить автовыгрузку, см. ниже).

### Если модель пропала из каталога

Скрипт пропускает модели, у которых в фиде битая ссылка на фото —
чтобы на сайте не появлялись пустые карточки. Сейчас так пропущена **Криель**:
её фотографии нет на сайте Max Christmas (ошибка 404).

Как починить: попросить того, кто ведёт сайт Max Christmas, загрузить фото
для этой модели. После следующего обновления она появится сама.

---

## Чего делать не надо

- **Не переносить на Тильду и другие конструкторы.** Шкала высот, просмотр
  отзывов и каталог из фида там не заработают — придётся собирать заново.
- **Не открывать `index.html` в Word.** Сломается кодировка, страница поедет.
  Только Блокнот, VS Code или Sublime.
- **Не переименовывать папку `assets`** — отвалятся все картинки.
- **Не удалять `privacy.html`.** Ссылка на политику обязательна по закону,
  тем более что теперь стоит Метрика.

---

## Если что-то пошло не так

**Нет картинок и шрифтов** — файлы залиты не в корень. Проверьте,
что `index.html` лежит прямо в `public_html`, а рядом с ним папка `assets`.

**Каталог пустой** — повреждён `index.html`, скорее всего открывали в Word.
Скачайте файл заново с GitHub.

**Через месяц сайта нет в поиске** — почти всегда забыт один из двух запретов
из шага 4. Проверьте `robots.txt` и поищите `noindex` в коде страницы.

**В Метрике нет данных** — счётчик включается только на адресе `elushka.ru`.
Если сайт временно живёт на другом домене или на тестовом поддомене,
данных не будет: нужно добавить этот адрес в список разрешённых
(строка `var HOSTS` в самом низу `index.html`).

**Видео не играет на iPhone** — нормально при включённом энергосбережении,
показывается первый кадр. Ничего не сломано.

## Про хостинг: GitHub или обычный

Сейчас сайт живёт на GitHub Pages — это бесплатно, с автоматическим HTTPS
и с автообновлением цен. К нему можно привязать домен elushka.ru.

**Но для боевого сайта российского магазина это рискованно.** С мая 2026 года
GitHub в России работает с перебоями: Роскомнадзор блокирует отдельные страницы,
доступность периодически падает. Полной блокировки нет, но часть покупателей
может не открыть сайт — и вы об этом не узнаете. Если планируется реклама
в Яндекс Директе, это прямые потери: за клик платите, а человек видит ошибку.

**Рекомендация:** боевой сайт — на российском хостинге (Timeweb, Beget, reg.ru,
150–300 ₽ в месяц). GitHub оставить как хранилище исходников и место,
где раз в месяц пересобирается каталог.

Тогда после каждого обновления цен нужно перезаливать файлы. Это можно
автоматизировать: в GitHub Actions добавляется шаг выгрузки по FTP на хостинг.
Настраивается один раз, потребуются FTP-доступы — скажите, если пойдём этим путём.

**Если всё же оставляете на GitHub Pages:**

1. В настройках репозитория → Pages → Custom domain вписать `elushka.ru`
2. Поставить галочку **Enforce HTTPS**
3. У регистратора домена прописать A-записи на IP GitHub:
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
4. Шаг 2 этой инструкции (заливка на хостинг) тогда не нужен

## Что стоит доделать потом

1. **Показать политику юристу** — текст написан под текущий сайт,
   но лучше проверить.
2. **Форма оптового прайса** — сейчас кнопка ведёт на сайт Max Christmas.
   Если нужна форма прямо на лендинге, потребуется обработчик: почта или CRM.
3. **Видео на первом экране весит 2,4 МБ** — это больше половины веса страницы.
   Если важна скорость на мобильном, ролик можно укоротить или сжать сильнее.
