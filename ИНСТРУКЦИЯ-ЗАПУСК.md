# Как запустить лендинг Ёлушка на elushka.ru

Сайт готов. Счётчик Метрики и цели уже вшиты в код.

Всего 5 шагов, примерно час работы. Шестой шаг — автообновление цен —
делается один раз и потом работает само.

---

## Шаг 1. Скачать файлы

1. Открыть https://github.com/pogorelova-marketing/elushka-landing
2. Зелёная кнопка **Code** → **Download ZIP**
3. Распаковать

---

## Шаг 2. Залить на хостинг

Скопировать в корень сайта — папка `public_html` или `www`
(файловый менеджер хостинга или FileZilla).

**Что заливать:**

```
index.html
privacy.html
sitemap.xml
assets/          ← вся папка целиком
```

**Что не заливать:** `data`, `tools`, `.github`, `overview.md`, `README.md`,
`ИНСТРУКЦИЯ-ЗАПУСК.md` — это рабочие файлы.

`robots.txt` — отдельно, о нём шаг 4.

⚠️ `index.html` должен лежать **в корне**: адрес `elushka.ru/index.html`,
а не `elushka.ru/какая-то-папка/index.html`. Иначе не будет картинок.

---

## Шаг 3. Домен и HTTPS

1. Направить домен **elushka.ru** на хостинг (A-запись у регистратора)
2. Включить бесплатный SSL-сертификат — в панели хостинга, раздел «SSL»
3. Настроить переадресацию на `https://elushka.ru` с адресов
   `http://elushka.ru` и `www.elushka.ru`

Готово, когда в адресной строке появился замок.

---

## Шаг 4. Открыть сайт для поиска

Сейчас сайт спрятан от Яндекса и Google. Запрет стоит **в двух местах**,
снять надо оба.

### 4.1. robots.txt

В скачанной папке есть **`robots-production.txt`**.
Переименовать его в **`robots.txt`** и залить на хостинг.

Старый `robots.txt` (с надписью `Disallow: /`) — не заливать вообще.

### 4.2. Строчка в двух файлах

Открыть `index.html` в Блокноте (не в Word!), найти вверху строку:

```html
<meta name="robots" content="noindex, nofollow">
```

Удалить её. **То же самое в `privacy.html`.** Перезалить оба файла.

### 4.3. Проверить

- `elushka.ru/robots.txt` — должно быть `Allow: /`
- На главной Ctrl+U (Cmd+Option+U на Mac), поиск слова `noindex` — ничего не найдено

Если пропустить — сайт **никогда не появится в поиске**.

## Шаг 5. Цели в Метрике

Счётчик **100250379** (тот же, что на старом сайте) уже стоит на обеих страницах
и включается только на адресе elushka.ru.

Код целей тоже вшит. Осталось создать цели в интерфейсе:

**Метрика → Настройка → Цели → Добавить цель → тип «JavaScript-событие»**

| Название цели (любое) | Идентификатор | Когда срабатывает |
|---|---|---|
| Переход в магазин Max Christmas | `mc_shop` | кнопка «Перейти в каталог» |
| Переход на Wildberries | `wildberries` | кнопка Wildberries |
| Переход на Ozon | `ozon` | кнопка Ozon |
| Запрос оптового прайса | `opt_price` | «Получить оптовый прайс» |
| Клик по модели ёлки | `model_click` | карточка в каталоге |
| Клик по телефону | `phone_click` | номер в подвале |

Главные — первые четыре: это маршруты покупки из ТЗ.

**Включите в настройках счётчика** Вебвизор и карту скроллинга: для одностраничника
важнее обычных визитов — видно, до какого блока долистывают.

**Проверка:** откройте сайт, нажмите кнопку Wildberries, посмотрите в Метрике
отчёт «Конверсии» — событие появится через несколько минут.

## Шаг 6. Автообновление цен (делается один раз)

Цены в каталоге вшиты в страницу. Каждое **1-е число в 06:00 по Москве**
GitHub сам скачивает свежий фид Max Christmas, пересобирает каталог,
подтягивает новые фото товаров и сжимает их.

Чтобы обновление попадало **на ваш хостинг**, нужно один раз дать доступ по FTP.

### 6.1. Добавить доступы

Открыть репозиторий → **Settings** → слева **Secrets and variables** → **Actions**.

Вкладка **Secrets**, кнопка **New repository secret**. Создать три штуки:

| Имя | Значение |
|---|---|
| `FTP_HOST` | адрес FTP-сервера, например `ftp.elushka.ru` |
| `FTP_USER` | логин FTP |
| `FTP_PASSWORD` | пароль FTP |

Если файлы лежат не в `/public_html`, добавьте четвёртый секрет
`FTP_DIR` с нужным путём.

### 6.2. Включить выгрузку

Там же вкладка **Variables** → **New repository variable**:

| Имя | Значение |
|---|---|
| `DEPLOY_FTP` | `on` |

Без этой переменной выгрузка не запускается — так сделано, чтобы случайно
ничего не залилось до того, как вы будете готовы.

### 6.3. Проверить

1. Вкладка **Actions** → слева «Обновление каталога из фида»
2. Справа **Run workflow** → зелёная кнопка **Run workflow**
3. Через минуту-две откройте сайт и посмотрите дату под каталогом —
   она должна стать сегодняшней

Этой же кнопкой обновляют цены вручную, когда они поменялись срочно,
не дожидаясь 1-го числа.

**Что выгружается:** `index.html`, `privacy.html`, `sitemap.xml` и папка `assets`.
`robots.txt` не трогается — то есть ваши настройки индексации не собьются.

### Если FTP-доступы давать не хотите

Тогда после каждого обновления файлы перезаливаются вручную: скачать
свежий `index.html` и папку `assets` с GitHub и положить на хостинг.
Раз в месяц — терпимо, но легко забыть, и цены на сайте разойдутся с магазином.

### Если модель пропала из каталога

Скрипт пропускает модели с битой ссылкой на фото в фиде — чтобы на сайте
не появлялись пустые карточки. Сейчас так пропущена **Криель**: её фотографии
нет на сайте Max Christmas (ошибка 404). Как загрузят — появится сама.

## Готово. Проверьте напоследок

- [ ] Сайт открывается на телефоне, ничего не съезжает вбок
- [ ] В блоке «Модели» работает шкала высот: меняешь высоту — меняются цены
- [ ] Фото отзывов открываются на весь экран по клику
- [ ] Кнопки ведут куда надо: каталог, WB, Ozon, оптовый прайс
- [ ] Внизу открывается политика конфиденциальности
- [ ] В адресной строке замок HTTPS
- [ ] В Метрике за сегодня появились визиты

Добавьте сайт в **Яндекс Вебмастер** и **Google Search Console**,
загрузите там `sitemap.xml` — поисковики найдут сайт за дни, а не за недели.

---

## Чего делать не надо

- **Не переносить на Тильду и другие конструкторы.** Шкала высот, просмотр
  отзывов и каталог из фида там не заработают — придётся собирать заново.
- **Не открывать `index.html` в Word** — сломается кодировка.
  Только Блокнот, VS Code или Sublime.
- **Не переименовывать папку `assets`** — отвалятся все картинки.
- **Не удалять `privacy.html`** — ссылка на политику обязательна по закону,
  тем более что стоит Метрика.
- **Не редактировать файлы прямо на хостинге**, если включена автовыгрузка:
  при следующем обновлении правки затрутся. Менять нужно в репозитории.

---

## Если что-то пошло не так

**Нет картинок и шрифтов** — файлы залиты не в корень. Проверьте, что
`index.html` лежит прямо в `public_html`, а рядом с ним папка `assets`.

**Каталог пустой** — повреждён `index.html`, скорее всего открывали в Word.
Скачайте заново с GitHub.

**Через месяц сайта нет в поиске** — почти всегда забыт один из двух запретов
из шага 4. Проверьте `robots.txt` и поищите `noindex` в коде страницы.

**В Метрике нет данных** — счётчик включается только на адресе `elushka.ru`.
Если сайт временно на другом домене, данных не будет: нужно добавить этот адрес
в строку `var HOSTS` внизу `index.html`.

**Автовыгрузка не сработала** — откройте Actions, найдите запуск с красным
крестиком, посмотрите шаг «Выложить обновление на хостинг». Обычно это неверный
логин, пароль или путь. Проверьте, что хостинг вообще разрешает FTP-доступ —
некоторые по умолчанию дают только SFTP.

**Видео не играет на iPhone** — нормально при включённом энергосбережении,
показывается первый кадр.

---

## Что стоит доделать потом

1. **Показать политику юристу** — текст написан под текущий сайт.
2. **Форма оптового прайса** — сейчас кнопка ведёт на сайт Max Christmas.
   Если нужна форма на лендинге, потребуется обработчик: почта или CRM.
3. **Видео на первом экране весит 2,4 МБ** — больше половины веса страницы.
   Если важна скорость на мобильном, ролик можно укоротить.
